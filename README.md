Объяснение кода:

    Чтение файла:
        Открываем файл в режиме чтения ('r').
        Считываем строки с помощью readlines().

    Сортировка строк:
        Убираем символы переноса строки \n с помощью strip().
        Сортируем строки с помощью sorted().

    Запись в новый файл:
        Открываем новый файл в режиме записи ('w').
        Записываем отсортированные строки, добавляя символ переноса строки \n обратно.

    Обработка ошибок:
        Если входной файл не найден, выводится сообщение об ошибке.
        Любая другая ошибка обрабатывается универсальным исключением.
